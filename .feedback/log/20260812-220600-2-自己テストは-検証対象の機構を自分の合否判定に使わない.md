# 自己テストは、検証対象の機構を自分の合否判定に使わない

根因: 指示欠陥。tests/test_smoke.sh は assert.sh の健全性を検証する土台テストだが、自分の合否も assert_summary で出していた。そのため assert_summary が常に exit 0 を返す壊れ方(=全テストが無条件成功になる最悪の壊れ方)を自分では検出できなかった。変異テストで発覚。独立した判定機構(自前カウンタ + 明示 exit)に置き換えて5種の変異すべてを検出できるようにした。テストの土台を書くときは「この機構が壊れたらこのテストは気づけるか」を変異テストで確認すること。
