# 変異テストの後始末に git checkout を使わない(未コミットの修正ごと消える)

護欄テスト(tests/test_doc_inventory.sh)が欠陥を捕まえるか確認するため6件の変異を順に入れ、毎回 `git checkout <file>` で戻した。しかし対象ファイルには同じセッションで加えた未コミットの修正が含まれており、変異と一緒に自分の作業も消えた(README.md / README.ja.md / docs/README.ja.md / plans 1件 / review 1件を再作成)。git checkout は「直前の変更」ではなく HEAD の内容へ戻すため、作業中のワークツリーでは復元手段にならない。変異の後始末は、事前に退避したコピーで戻すか、隔離ディレクトリの fixture 上で変異させる。根因: 実行誤り
