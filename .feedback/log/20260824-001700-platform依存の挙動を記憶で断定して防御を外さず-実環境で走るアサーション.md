# platform依存の挙動を記憶で断定して防御を外さず、実環境で走るアサーションで先に確かめる

PR #13レビュー対応。Windows の Python 出力に CR が混ざるかを『CPython の create_stdio() は newline="\n" を渡す』という記憶から断定し、既存のCR除去を死にコードとして削除した。Windows CI が実出力 true\r\n で否定し、修正を逆向きに取り直すことになった。手元(macOS/Linux)で再現できない platform 挙動は、記憶を根拠に既存の防御を外さない。順序を逆にする — 実環境で走るアサーションを先に足し、その結果を見てから防御の要否を決める。今回は検証テストを同時に入れていたためCIで1往復で判明したが、テストが無ければ利用者環境で顕在化していた。根因: 実行誤り
