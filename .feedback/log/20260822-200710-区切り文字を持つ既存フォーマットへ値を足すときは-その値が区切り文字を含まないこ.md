# 区切り文字を持つ既存フォーマットへ値を足すときは、その値が区切り文字を含まないことを確認する

個人設定レイヤの実装で、--list-checks の出所へレイヤ名を "local:checks.ruff" の形で前置した。出所は HARNESS_CHECK_SEVERITY へ "id:severity:出所" の形で詰められ、シェル側の読み出しは ${entry##*:}(最後のコロン以降)だったため、レイヤ名が黙って落ちて出所が "checks.ruff" のまま表示された。エラーにならず、値の一部だけが静かに消える壊れ方だった。フォーマット側のコメントには「検査IDと severity と出所はいずれも空白を含まない」と書かれていたが、コロンについては触れられておらず、パース実装(${entry##*:})を読むまで気づけなかった。既存の直列化フォーマットへ新しい値を足すときは、区切り文字の制約をパース実装まで読んで確認する。env 由来の "env.FEEDBACK_CHECK_SKIP" と同じドット形式へ変更して解決した。根因: 実行誤り
