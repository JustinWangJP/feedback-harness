# ツール未導入を発見しても勝手にインストールせず、必ずユーザーの許可を得てから実行する

適用範囲拡張の設計で候補ツールが未導入と分かった際、brew install を提案・実行しようとした。根因: 指示欠陥(インストールは環境を変える行為であり許可を要する、という規約が無かった)。ハーネス自身も npx --no-install で同じ原則を既に守っている
