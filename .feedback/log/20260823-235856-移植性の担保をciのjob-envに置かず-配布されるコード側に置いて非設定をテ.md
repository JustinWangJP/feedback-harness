# 移植性の担保をCIのjob envに置かず、配布されるコード側に置いて非設定をテストで固定する

PR #13レビュー。Windows対応のUTF-8指定(PYTHONUTF8/PYTHONIOENCODING)を .github/workflows/ci.yml の job env にだけ置いたため、Windows CIは緑だが利用者のGit Bashでは feedback.sh list / rules / --list-checks が UnicodeEncodeError で落ちる状態だった。CIだけが「誰も使っていない環境」を検証していた。修正: 指定を scripts/lib.sh の _harness_python_exec へ移し、ci.yml からは意図的に外して tests/test_oss_baseline.sh で非設定をアサート、tests/test_python_boundary.sh が ambient を ascii へ潰して担保を検証する。根因: 実行誤り
