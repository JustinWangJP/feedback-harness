# パッケージマネージャ固有のコマンドは、新しいスクリプトを足すたびにPM判定を書き直す必要がある

根因: 指示欠陥

P2 で check.sh の 'npm ls --all' を npm 限定にする修正(e21b2bc: pnpm/yarn で健全なプロジェクトが usema error で誤FAILする)を入れたが、P3 で新規追加した audit.sh の 'npm audit' に同じ判定が適用されず、同じ欠陥クラスが再発した。pnpm-lock.yaml しか無いプロジェクトで npm audit は ENOLOCK(exit 1)を返し、脆弱性ゼロなのに『脆弱性が検出されました』と誤報告する(2026-08-17 実測)。

同種のコマンド: npm ls --all(pnpmに--allが無い) / npm audit(package-lock.json しか読めない) / npx(他PMではdlx)。

対処: npm 固有コマンドを新規に追加するときは、lockfile または PM を判定して npm 以外は理由付きSKIPにする。既存スクリプトに同じコマンドの前例が無いか grep で確認してから書く。
